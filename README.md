# SPARQL Threat Model

This is a living document for the current latest SPARQL Query 
speciifcations. Howver, it is not synchronized tot he publication
cycle of those documents and the threat mode will evolve separately.

Currently, it is use to inform writing the 
"[Security Considerations](https://www.w3.org/TR/sparql12-query/#security)"
section of SPARQL Query.

It will add coverage of SPARQL Update, SPARQL Protocol and SPARQL Graph
Store Protocol.

Current draft: https://w3c.github.io/sparql-threat-model/threat-model/sparql-threat-model.html
